# Figures

This directory contains the nine figure files used by the paper.

- Run `python3 assets/generate_raster_figures.py` from the repository root to
  regenerate the seven PNG diagrams.
- Run `python3 assets/generate_vector_figures.py` to regenerate the two TikZ-
  based vector PDFs (`hamming_balls_discrete.pdf` and
  `polarization_recursion.pdf`).

The generated figure files are committed because they are direct inputs to
`main.tex`; the scripts are retained so their appearance can be revised.
